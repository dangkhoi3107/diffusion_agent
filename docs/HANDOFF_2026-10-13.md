## 2. Bối cảnh kỹ thuật

### 2.1 Pipeline sinh ảnh (giữ nguyên, code từ 14/09)

- Model: SD 1.5 + ControlNet softedge (HED) + canny, hai nhánh (nền / subject), blend theo mask viền HED của subject.
- Prompt subject: `a hidden {tên loài} silhouette seamlessly integrated into the background, subtle facial cues, optical illusion, camouflage`.
  - Negative prompt: `sticker, pasted object, sharp outline, cartoon, text, watermark, logo, extra limbs, deformed, low quality, high contrast`.
  - Tên loài lấy từ `label` của subject (ví dụ cattle, parrot, spider).
- **C00 = cấu hình mặc định của luận văn** (`configs/default.yaml`, `camo/config.py`):

| Nhóm | Tham số | C00 | Ý nghĩa |
|---|---|---|---|
| blend | profile / start_frac / end_frac / alpha_end | decay / 0,05 / 0,56 / 0,54 | Mức trộn nhánh subject trong vùng mask, theo bước |
| sampling | bg_strength | 0,52 | Mức vẽ lại nền: cao thì nền "mềm" hơn, subject dễ nổi hơn |
| sampling | guidance_sub / guidance_bg | 2,3 / 1,2 | Độ mạnh prompt của nhánh subject / nhánh nền |
| sampling | steps, scheduler, seed | 57, unipc, 1234 | |
| control | softedge_scale / canny_scale / end_frac / layer_weights | 1,5 / 0,02 / 0,84 / A | ControlNet; A = tắt các tầng độ phân giải cao |
| mask | blur / gamma / floor / ceiling | 11 / 0,5 / 0,05 / 0,9 | mask = (viền^gamma − floor) / (ceiling − floor). **Chỉ là mask viền**, phần thân bên trong gần như đen |
| layout | scale | 1,0 | |

- **Nút mới (mặc định TẮT, để giữ output như cũ):**
  - `mask.border_px`: xoá mask trong N px quanh mép. HED vẽ một khung quanh mép ảnh, chiếm khoảng 15% lượng mask; khi bật thì ảnh trông như base.
  - `seed_per_pair: true` ở đầu file lưới (`camo/pilot.py pair_seed`): mỗi cặp một seed ổn định (sha256 của pair id), giữ nguyên qua mọi config của cặp. **Lưới v4 bật cái này.**

### 2.2 Hai model

- **Model 1 (Observer, giai đoạn A đã có code):** `camo/backbone.py`, `camo/observer.py`, `scripts/train_observer.py`.
  - DINOv2-small đóng băng (768 số) trên bộ ba [render, nền, render − nền] → MLP, head CORAL visibility (missing < subtle < good < too_visible) + head broken.
  - Chạy CPU ở máy trong venv `~/.venvs/camo-ml` (python hệ thống không có torch).
  - Kết quả 12/10 (375 nhãn cũ, chưa có b1/b2/b0v3): khớp đạt/không đạt **0,68**, exact 0,61. CLIP 0,68; đoán lớp nhiều nhất 0,41; GPT vision 0,50–0,57.
- **Head C (Recognizer) đã xong:** `outputs/recognizer/`, 100 lớp, top-1 94,4%, 18/18 subject v1 đúng, phát hiện loài lạ AUROC 0,915.
- **Model 2 (Proposer, code xong, chưa train thật):** `camo/proposer.py`, `scripts/train_proposer.py`.
  - GRU nhỏ. h0 = đặc trưng nền chiếu **PCA 16 chiều** (không whitening) + dropout.
  - Train BC (DAgger) rồi REINFORCE (`rl_lr` nhỏ).
  - Thưởng: +1 khi đạt, −0,1 mỗi lần render, −1 nếu hết 5 lượt mà không đạt.
  - Có `NetPolicy(Policy)` cắm vào Controller.
  - Trên dữ liệu giả 768 chiều: success 1,0 với 1,2–1,6 lượt render, so với Rule 3,0. Không có PCA thì mạng học vẹt nhiễu (success 0,44).
  - **Cần ít nhất 10 cặp train có đủ nhãn cả 15 config của lưới hiện tại.**
- **Kế hoạch tổng** (docs/AGENT_PLAN.html, artifact https://claude.ai/artifact/ME399mdv99wpLyMEwiZqQ9): **AGENT_PLAN đã cũ** ở phần lưới và dữ liệu, cần cập nhật theo file này.
